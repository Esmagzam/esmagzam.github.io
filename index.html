01. Миний тухай

Сайн байна уу. Намайг Самалхан Есмагзам гэдэг. Би фронтенд вэб хөгжүүлэлт болон мобайл технологиор дагнасан программ хангамжийн инженер. Одоогоор Хөдөө Аж Ахуйн Их Сургуульд Программ хангамжийн чиглэлээр төгсөх курст суралцаж байна.

Вэб хөгжүүлэлтийн чиглэлээр TypeScript, JavaScript, Tailwind CSS болон семантик HTML5/CSS3 ашиглан ямар ч дэлгэцэнд зохицсон, цэвэр кодтой фронтенд шийдлүүдийг боловсруулдаг. Харин мобайл орчинд Flutter & Dart болон Supabase, PostgreSQL ашиглан олон улсын зах зээлд өрсөлдөхүйц 4 бодит iOS аппликейшнийг бие даан нийтэлсэн туршлагатай.

Би зөвхөн код бичих бус, Figma дээрх хэрэглэгчийн интерфэйс дизайнаас эхлэн өгөгдлийн сангийн зөв зохион байгуулалт, n8n ажлын урсгалын автоматжуулалт болон цэвэр архитектурын зарчмыг бүх бүтээгдэхүүндээ шингээдэг.

05. Туршлага

Фронтенд & Мобайл хөгжүүлэгч (Бие даасан)

2023 — Present
Бүтээгдэхүүн хөгжүүлэлт · Вэб интерфэйс ба Мобайл апп
  • HTML5, CSS3, орчин үеийн JavaScript болон Tailwind CSS ашиглан олон төрлийн дэлгэцэнд зохицсон, цэвэр бүтэцтэй вэб интерфэйсүүдийг хөгжүүлсэн.
  • TypeScript ашиглан хэрэглэгчийн талын логикийг алдаагүй, төрөлжсөн (type-safe) байдлаар бичиж өгөгдлийн боловсруулалтыг найдвартай болгосон.
  • Figma дээрх UI дизайнаас эхлэн эцсийн хувилбар хүртэл 4 бодит мобайл аппликейшнийг бие даан архитектурчилж, Apple App Store-д олон улсын зах зээлд нийтэлсэн.
  • Supabase болон PostgreSQL орчинд өгөгдлийн бааз төлөвлөж, Row-Level Security (RLS), хэрэглэгчийн баталгаажуулалт болон REST API холболтуудыг нэвтрүүлсэн.
  • Firebase Authentication, Firestore өгөгдлийн сан зэрэг cloud шийдлүүдийг бодит цагийн өгөгдөл синхрончлолд амжилттай нэгтгэн ажилласан.
  • Ажлын урсгалыг оновчлох, өгөгдлийн боловсруулалтыг автоматжуулахад n8n болон Git хувилбар удирдлагыг ашигласан.
